# StockPilot v28 — Operations-first UX

Bu versiya yalnız vizual düzəliş deyil. Panelin istifadə məntiqi dəyişdirilib.

## Dashboard / Şəxsi sifarişlər
- Yuxarıda yeni **“Bu gün nə vacibdir?” İş mərkəzi** əlavə edildi.
- Yeni müştəri sifarişləri, riskli stok və aktiv şəxsi sifarişlər bir baxışda görünür.
- **Action queue** kritik stok və gözləyən sifarişlər üçün birbaşa keçid verir.

## Stok
- Sadə “yalnız az qalanlar” checkbox yanaşması əvəzinə **Stock Health** sistemi əlavə edildi:
  - Kritik
  - Az qalan
  - Sağlam
- Hər məhsul kartında stok sağlamlığı badge-i görünür.
- Mobil və desktop üçün filterlər toxunmaq/klikləmək üçün daha rahatdır.

## Müştəri sifarişləri
- **Board / Siyahı** görünüşü əlavə edildi.
- Board status axını: Yeni → Təsdiqləndi → Hazırlanır → Kuryerdə.
- Hər sifariş kartında növbəti mərhələyə keçmək üçün **bir kliklik əsas action** var.
- Köhnə status select-i saxlanılıb ki, istənilən statusa əl ilə keçmək mümkün olsun.
- “Redaktə” adı **“Detallar”** olaraq dəyişdirildi.

## Inspector davranışı
- Desktop-da modal pəncərələr artıq mərkəzdə konteksti örtmək əvəzinə **sağdan açılan inspector panel** kimi görünür.
- Mobildə klassik rahat modal davranışı saxlanılır.

## Əvvəlki v26/v27 düzəlişləri də qalır
- 24 saatlıq vaxt seçimi
- Sürətli tarix/saat seçimləri
- Daha rahat checkout
- Login/register density düzəlişləri
- Panel spacing və topbar simplification
