# StockPilot v39.2 — Register Hotfix

## Problem
v39/v39.1 qeydiyyat endpoint-i `users` və `user_state` cədvəllərinin deploy-dan əvvəl `schema.sql` ilə yaradıldığını güman edirdi. D1 migration ayrıca icra edilmədikdə yeni hesab yaratmaq 500 xətası ilə uğursuz ola bilərdi.

## Düzəliş
- Worker artıq register/login-dən əvvəl əsas auth cədvəllərini özü `CREATE TABLE IF NOT EXISTS` ilə təmin edir.
- `users` + `user_state` yaradılması ardıcıl və təhlükəsizdir.
- Yeni hesabın `users` və `user_state` insert-ləri D1 `batch()` ilə birlikdə işləyir.
- Database write xətası üçün daha düzgün istifadəçi mesajı əlavə edildi.
- Username UNIQUE konflikti ayrıca 409 kimi qaytarılır.
- Register fetch-də `credentials: same-origin` açıq göstərildi ki, yaradılan HttpOnly session cookie dərhal istifadə olunsun.
- v39.1 case-insensitive login hotfix saxlanılıb.
