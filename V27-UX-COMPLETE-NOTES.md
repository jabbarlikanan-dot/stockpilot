# StockPilot v27 — UX completion pass

Bu paket v26 mağaza/checkout dəyişikliklərini saxlayır və əvvəl danışılan, amma v26-da tətbiq olunmayan əsas UX dəyişikliklərini də əlavə edir.

## Auth
- Login və register səhifələrində böyük boşluqlar azaldıldı.
- Hero və form arasında density balansı düzəldildi.
- Form kartı daha kompakt və ekranın mərkəzinə yaxınlaşdırıldı.
- Mobil görünüşdə hero qısaldıldı ki, forma daha tez görünsün.
- Register sahələri daha sıx və rahat ritmlə yerləşdirildi.

## Panel
- Heading və content spacing daha balanslı edildi.
- Çox geniş ekranlarda content-in həddən artıq yayılması məhdudlaşdırıldı.
- Sidebar bir qədər daha kompakt edildi.
- Dashboard topbar-dakı ikinci dərəcəli Excel/quote əməliyyatları `Daha çox` menyusuna yığıldı.
- `Mağazam`, bildiriş və profil əsas action kimi görünən saxlanıldı.
- Mobil paneldə əsas action-lar qorunub, ikinci dərəcəli topbar əməliyyatları gizlədilir.

## Store / Checkout (v26-dan qalır)
- 24 saat formatı.
- Quick date/time seçimləri.
- 3 mərhələli daha rahat checkout.
- Card əsaslı çatdırılma və ödəniş seçimi.
- Məhsul axtarışı və səbət xülasəsi.

- `login.html`
- `register.html`
- `dashboard.html`
- `redesign.css`
- v26-dan: `store.html`, `store.css`, `store.js`, `orders.js`
