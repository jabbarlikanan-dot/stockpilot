# StockPilot v30 — Compact Layout & Store Filtering

- Dashboard operations hub böyük iki paneldən kompakt status rail-a çevrildi.
- Statuslar rəngli dot/icon məntiqində verilir.
- Məhsul workspace-də soldakı panel artıq cədvəlin hündürlüyünə stretch olmur.
- Şəxsi sifariş məhsul cədvəli 12 sütundan 7 əsas sütuna endirildi; horizontal scroll aradan qaldırıldı.
- Secondary məlumat məhsul detail/inspector axınında qalır.
- `Daha çox` menyusu sabit vertikal dropdown-a çevrildi.
- App page gutters azaldıldı, header/topbar tam genişlikdə və daha balanslı oldu.
- Store header tam genişlikdədir.
- Store sağ hero paneli promosyon mətnindən real məhsul filter panelinə çevrildi:
  - adla axtarış
  - kateqoriya
  - stok filtri
  - sıralama
- Store checkout-dan quick date/time chip-ləri və artıq izah mətnləri çıxarıldı.
- Saat seçimi tək bir 24-saat dropdown kimi saxlanıldı.
